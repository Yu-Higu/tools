# Image Coordinate System Overlay Tools (画像座標系オーバーレイツール)

画像上に2D/3Dの座標軸・グリッド・目盛りをインタラクティブに重畳し、スケール校正や画像書き出しを行えるブラウザベースのWebツール群です。

---

## 概要

実験データやグラフ画像、3Dモデルのキャプチャ画像などに対して、正確な原点設定、回転角度の調整、物理距離に基づくスケール校正（`px/unit`）を行った上で座標系を重畳できます。ブラウザのみで動作するため、特別なライブラリのインストールは不要です。

本リポジトリには以下の2種類のツールが含まれます。

1. **`interactive_image_coordinate_overlay_tool_2.html`**
   * 2D 座標軸の重畳に特化した軽量版ツール（英語版UI）。
2. **`interactive_image_coordinate_overlay_tool_3D_2.html`**
   * 2D/3D 座標軸（Pitch / Yaw / Roll 回転対応）をサポートした高機能版ツール（日本語 / 英語 バイリンガル対応）。

---

## 主な機能

* **画像の読み込みと書き出し**
  * 任意の画像ファイル（PNG, JPEG等）を読み込み可能。
  * 座標軸を重畳した画像を合成し、PNGフォーマットで書き出し（ダウンロード）。
* **直感的なマウス操作**
  * **原点 & X軸設定**: 画像上をドラッグして原点位置とX軸のベクトル方向（回転）を一括で指定。
  * **距離キャリブレーション**: 画像上の既知の2点間をドラッグ計測し、実物理距離を入力することで自動的に `px/unit` スケールを算出・適用。
* **柔軟な表示カスタマイズ**
  * X, Y, Z 各軸の範囲（Min / Max）および目盛り間隔（Grid Interval）の設定。
  * グリッド線、数値ラベル、原点マーカーの表示/非表示切り替え。
  * Y軸の反転（画面座標系 / 通常の数学座標系）対応。
  * 目盛り線の向き（両側 / 内向き / 外向き）の調整。
  * 軸の色および軸名（ラベル）のカスタマイズ。
* **3D 投影機能（3D対応版のみ）**
  * Pitch（X軸周り）、Yaw（Y軸周り）、Roll（Z軸周り）のスライダー操作による3D空間座標系の自由な視点調整。
  * 2D / 3D 座標モードのワンタップ切り替え。

---

## 使い方

1. リポジトリをクローンまたはダウンロードします。
2. 対象の HTML ファイル（`interactive_image_coordinate_overlay_tool_3D_2.html` など）を Web ブラウザ（Chrome, Edge, Firefox 等）で直接開きます。
3. 画面右上の **「画像を開く (Open Image)」** ボタンから任意の画像を選択します。
4. **操作手順**:
   * **軸の設定**: 「原点 & X軸指定」モードで画像上をクリック＆ドラッグし、原点位置とX軸の傾きを設定します。
   * **スケール校正**: 「距離校正」モードで長さが分かっている箇所をドラッグし、実際の物理距離を入力して「計算スケールを適用」を押します。
   * **調整**: サイドバーから軸範囲、目盛り間隔、カラー、3D回転角度などを調整します。
5. **書き出し**: 画面右上の **「画像書き出し (Export Image)」** ボタンを押すと、重畳画像のPNGファイルが保存されます。
